# Professional schema examples

These three files illustrate a single spectrum, two same-edge spectra, and two
different absorption edges. They are schema contracts, not experimental data or
scientific reference results. File hashes and byte counts are placeholders, so
they must not be imported as verified resource bundles or used as fitting tests.

The examples share an explicitly declared atom-pair distance. Each edge keeps its
own S02, E0 and sigma2 declarations. `recomputable` is false until actual raw
spectra and FEFF resources are supplied and checked.
